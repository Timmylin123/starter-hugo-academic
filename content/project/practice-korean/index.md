A fast, lightweight game for practicing Korean pronunciation through Hangul recall. Players choose focused practice sets for the alphabet, basic consonants, double consonants, simple vowels, or compound vowels, type the matching romanized pronunciation, receive immediate feedback, and review results at the end of each round.
